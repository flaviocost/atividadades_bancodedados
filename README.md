# 🗄️ Atividades de Banco de Dados

Repositório dedicado ao armazenamento de scripts SQL, modelagens de dados e exercícios práticos desenvolvidos na disciplina/estudos de **Banco de Dados Relacional**.

---

## 📌 Sobre o Repositório

Este espaço reúne a prática de modelagem conceitual e lógica, além da criação e manipulação de tabelas, chaves primárias/estrangeiras e consultas utilizando SQL.

---

## 🛠️ Tecnologias e Ferramentas Usadas

- **SGBD:** MySQL / PostgreSQL / SQLite
- **Modelagem:** Draw.io (Diagramas Entidade-Relacionamento e UML)
- **Controle de Versão:** Git & GitHub

---

## 📂 Conteúdos e Conceitos Praticados

- [x] Modelagem de Dados (DER e Diagramas Lógicos)
- [x] Criação de Bancos de Dados e Tabelas (`CREATE DATABASE`, `CREATE TABLE`)
- [x] Chaves Primárias (`PRIMARY KEY`) e Estrangeiras (`FOREIGN KEY`)
- [x] Inserção e Manipulação de Dados (`INSERT`, `UPDATE`, `DELETE`)
- [x] Consultas Básicas e Filtros (`SELECT`, `WHERE`, `ORDER BY`)
- [x] Relacionamentos entre Tabelas (`JOIN`)
